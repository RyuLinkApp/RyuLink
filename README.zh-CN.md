# RyuLink

[English](README.md) | **简体中文**

RyuLink 是一个面向 Nintendo Switch 自制系统用户的社区联机工具，旨在帮助支持本地无线 / LAN 联机的游戏，通过 RyuLink 房间跨互联网连接。

> 当前处于公开测试阶段。不同游戏、网络环境和系统配置下的兼容性与稳定性可能有所差异。

## RyuLink 能做什么

- 让受支持的本地多人联机通过互联网连接
- 提供基于房间的匹配与网络中继服务
- 面向 Nintendo Switch 自制系统 / Atmosphère 环境
- 将游戏内容与联机服务本身保持分离

## RyuLink 不提供什么

RyuLink **不提供**游戏、ROM、固件、加密密钥、Title Key 或其他受版权保护的游戏内容。

用户需要自行遵守所在地适用的法律法规以及相关平台规则。
