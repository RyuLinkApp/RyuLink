# RyuLink

RyuLink is a community networking tool for Nintendo Switch homebrew users. It is designed to help supported local-wireless / LAN multiplayer games connect across the Internet through RyuLink rooms.

> Public beta project. Compatibility and stability may vary by game, network environment, and system setup.

## What RyuLink does

- Connects supported local multiplayer sessions over the Internet
- Provides room-based matchmaking and network relay services
- Targets Nintendo Switch homebrew / Atmosphère environments
- Keeps game content separate from the networking service

## What RyuLink does not provide

RyuLink does **not** distribute games, ROMs, firmware, encryption keys, title keys, or other copyrighted game content.

Users are responsible for complying with the laws and platform rules applicable to them.

## Downloads

Official public builds will be published through the **GitHub Releases** section of this repository.

For security, only download packages published by the `RyuLinkApp` account from this repository.

## Status

RyuLink is currently in public beta. We are actively testing compatibility, connection stability, and server capacity.

## Language

The current application interface may still contain Chinese text. English localization is planned and will be improved during the beta.

## Feedback

If you encounter a reproducible problem, please include the game name, RyuLink version, system environment, network type, and steps to reproduce when reporting it.
