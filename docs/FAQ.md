# RyuLink FAQ

## What is RyuLink?

RyuLink is a community networking tool for Nintendo Switch homebrew users. It is designed to carry supported local-wireless or LAN multiplayer traffic across the Internet through RyuLink rooms.

## Can players use different Wi-Fi networks?

Yes. Cross-network play is one of RyuLink's main goals. During the public beta, actual compatibility can still vary by game, game version, router, ISP, NAT behavior, and network quality.

## Does RyuLink replace Nintendo Switch Online?

No. RyuLink focuses on supported local-wireless / LAN multiplayer scenarios and is not a replacement for Nintendo's official online services.

## Does RyuLink include games or game files?

No. RyuLink does not provide games, ROMs, firmware, encryption keys, title keys, or other copyrighted game content.

## Which games are supported?

Compatibility is still being tested during the public beta. A game working with local multiplayer does not automatically guarantee that every mode will work through RyuLink.

When reporting compatibility, include the exact game title and game version.

## Do all players need the same RyuLink version?

Using the same current release is strongly recommended. Mixing different versions may cause discovery, connection, protocol, or stability problems.

## Can I switch RyuLink rooms?

Yes, room selection is part of the RyuLink service. Players who want to play together should join the same room before starting the relevant multiplayer session.

## Why can I see a room but fail when the game starts?

Discovery and actual gameplay can use different network traffic. A room being visible therefore does not guarantee that the full gameplay path is compatible or healthy.

If this happens, report the exact game, RyuLink version, network types on both consoles, where the game stops progressing, and whether the problem is reproducible.

## Is the RyuLink source code hosted in this repository?

No. This public repository is currently used as the official product page, documentation, public-beta feedback channel, and release-distribution location.

## Where should I download RyuLink?

Only use releases published by the `RyuLinkApp` account in this repository. Avoid unofficial repacks or third-party mirrors unless they are explicitly linked by the project.

## How should I report a bug?

Open a GitHub Issue and use the bug-report template. Include:

- RyuLink version
- Game title and version
- Console / homebrew environment
- Network type for each console
- Exact reproduction steps
- Expected and actual behavior
- Relevant logs, if available

Do not post passwords, access tokens, private keys, personal information, or other secrets in public issues.

## Is RyuLink affiliated with Nintendo?

No. RyuLink is an independent community project and is not affiliated with, endorsed by, or sponsored by Nintendo.
