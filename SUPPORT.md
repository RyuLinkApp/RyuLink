# RyuLink Support

RyuLink is currently in public beta. The fastest way to get useful help is to choose the right reporting path and include enough context for the issue to be reproduced.

## Before opening an Issue

Please check:

- [Installation guide](docs/INSTALLATION.md)
- [Frequently asked questions](docs/FAQ.md)
- The latest GitHub Release notes for known limitations

Also confirm that all participating users are running the same current RyuLink build where possible.

## Connection or compatibility problems

Use the **Bug Report** Issue template and include:

- RyuLink version
- Game name and game version
- Nintendo Switch / Atmosphère environment
- Network type on each console, such as Wi-Fi, hotspot, or another Internet connection
- Whether room discovery works
- Whether joining the room works
- The exact point where the session fails
- Reproduction steps
- Relevant logs with secrets removed

Please avoid descriptions such as "it does not work" without reproduction details; they are usually not enough to diagnose networking problems.

## Feature requests

Use the **Feature Request** Issue template. Describe the problem you want solved rather than only proposing an implementation.

## Security issues

Do not publish sensitive security details in a normal Issue. Follow [SECURITY.md](SECURITY.md).

## What not to post

Never include:

- Passwords
- Access tokens
- Private keys
- Authentication cookies
- Full account credentials
- Private server configuration containing secrets
- Personal information that is not necessary to reproduce the problem

## Project scope

This repository is used for RyuLink documentation, public-beta feedback, and official binary releases. It is not currently a public source-code repository.

RyuLink does not provide support for obtaining games, ROMs, firmware, encryption keys, title keys, or other copyrighted game content.
